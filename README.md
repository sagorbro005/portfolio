## 💎 Design & Architecture Highlights

- 🌌 **Dark Glassmorphism Aesthetic**: Deep space dark canvas (`#070a12`) with frosted glass panels (`backdrop-filter: blur(16px)`), electric emerald (`#10b981`), cyber cyan (`#06b6d4`), and radiant violet (`#8b5cf6`) ambient glow accents.
- ⚡ **Interactive Neural Canvas**: Custom HTML5 particle matrix engine in the hero section that dynamically moves and connects nodes based on cursor proximity.
- 🎴 **3D Perspective Card Tilt**: Micro-interactive 3D tilt effects on cards for a tactile experience.
- 📊 **Scroll Progress Indicator**: Top gradient line tracking scroll position.
- 📋 **1-Click Copy-to-Clipboard**: Quick copy buttons for email (`sagorbro005@gmail.com`) and phone (`+8801811008229`) with animated toast feedback.
- 📱 **Fully Responsive Layout**: Built with modern CSS Grid, Flexbox, and fluid typography (`Outfit` & `Plus Jakarta Sans`).

   ```bash

   cd portfolio
   ```

2. **Run Locally**:
   Simply open `index.html` in any web browser, or start a lightweight local web server:
   ```bash
   npx serve .
   # or using Python:
   python -m http.server 8000
   ```
